就職選考 統合管理　{VERSION}
========================================

学校斡旋就職の選考業務（求人票・成績・校内順位・選考会議・職場見学・応募・報告）を、
1つのページで進めるためのツールです。インストールは不要で、インターネットにも接続しません。


■ 使い始める（はじめの1回）
----------------------------------------
1. zip ファイルを右クリック →［プロパティ］→ 下の方の［許可する］にチェック →［OK］
   （「許可する」が出ない場合は、そのまま次へ）
2. zip を右クリック →［すべて展開］。必ず展開してから使ってください。
   （zip の中で、そのまま起動.bat を開くと動きません）
3. 展開してできたフォルダの中の「起動.bat」をダブルクリック。
   ・画面が開けば成功です。
   ・「Windows によって PC が保護されました」と出たら、［詳細情報］→［実行］を選びます。
   ・それでも開けないときは、「site」フォルダの「index.html」を Edge にドラッグ＆ドロップしてください。
4. 最初にパスワードを聞かれます。パスワードは、配布した担当者から別途お伝えします（このブラウザでは最初の1回だけ）。
   ※ これは「うっかり開かれない」ための簡易な鍵です。生徒のデータは暗号化されません。
   　 パスワードを変えるときは、開発メモ（docs\CLAUDE.md）の「起動時のパスワード」を見てください。
5. 左のメニューの「設定」で、校長名・進路指導主事名・学科の番号の範囲を確認・入力します。
6. 右上の［名前を付けて保存］で、データファイル（.json）を保存します。
   以後の作業は、［上書き保存］（Ctrl+S）で同じファイルに保存されます。


■ 次に使うとき
----------------------------------------
「起動.bat」をダブルクリック → 右上の［開く］で、保存したデータファイル（.json）を選びます。
デスクトップに「起動.bat」のショートカットを作っておくと便利です。


■ 大事な注意
----------------------------------------
・生徒の個人情報は「データファイル（.json）」に保存されます。この zip にはデータは入っていません。
  データファイルは、校内の決められた場所（または USB）にだけ保存してください。
  インターネット上のサービスや、誰でも見られる共有フォルダには置かないでください。
・同時に複数人で編集することはできません。使うのは1人ずつにしてください。
・Microsoft Edge または Google Chrome で使います。
・作業の区切りごとに［上書き保存］を押してください。節目に日付入りのコピーを残すと安心です。


■ 新しい版に入れ替えるとき
----------------------------------------
新しい zip を展開し、古い「site」フォルダと「起動.bat」を入れ替えるだけです。
データファイル（.json）は別の場所にあるので、そのまま使えます。


■ 使い方
----------------------------------------
画面左のメニュー「使い方」に、年間の手順と各画面の操作が書いてあります（印刷もできます）。


■ 中身
----------------------------------------
起動.bat                 … ダブルクリックで起動
site\                    … プログラム本体（index.html から始まります）
docs\設計書.md           … 設計・引き継ぎ用の資料
docs\00_設計プラン.md    … 最初の計画
docs\CLAUDE.md           … AI（Claude Code）で修正を続けるときの開発メモ

使っている部品：SheetJS 0.20.3（Apache-2.0 ライセンス。site\lib に同梱）
