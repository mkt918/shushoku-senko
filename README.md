# 就職選考統合管理

高校の就職選考（学校斡旋）の事務を、ひとつの画面にまとめたツールです。サーバーを使わず、ブラウザだけで動きます。

- 求人票の管理、校内順位（ポイント）、選考会議、職場見学、応募・受験、ハローワーク様式13、進路決定、年度末の資料までを扱います。
- **生徒のデータはこのサイトに送られません。** 入力した内容は、使っているパソコンのブラウザと、自分で保存するファイル（JSON）にだけ残ります。
- 外部のサービスやフォントは読み込みません（Excel の読み込みに使う SheetJS だけを `site/lib/` に同梱しています）。

## 使い方

1. 公開ページ（GitHub Pages）を Edge または Chrome で開きます。
2. 最初に［設定］で、学校名・住所・電話・校長名・進路指導主事名・管内の市町などを入力します（初期値は空欄です）。
3. 作業の区切りごとに「名前を付けて保存」でデータ（JSON）を保存し、次に使うときは「開く」で読み込みます。

`site/index.html` をダブルクリックして開くこともできます（`起動.bat` は Windows 用の起動補助）。

設計・引き継ぎの詳細は [設計書.md](設計書.md)、開発メモは [CLAUDE.md](CLAUDE.md) を参照してください。

## このリポジトリに含まれないもの

**生徒・教員・企業担当者の情報と、学校を特定できる情報は含まれません。** 保存した JSON、旧 Excel/Word、CSV、PDF、配布 zip は `.gitignore` で上げないようにしています。データは、利用する学校のパソコン（校内の決められた場所・USB）にだけ置きます。

初回に聞かれるパスワードは、うっかり開かれないための簡易の鍵です（データを暗号化するものではありません）。

## 部品

SheetJS 0.20.3（Apache-2.0。`site/lib/` に同梱）。配布用 zip の作り方は `python tools/build_zip.py`。
